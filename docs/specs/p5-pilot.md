# Phase P5: Pilot in one branch

Phase: P5   Disciplines: FE, EL, EX   Owner: <you>   Status: outline
(Run `/fg-spec refine docs/specs/p5-pilot.md` first.)

## Goal
Three technicians and the branch's coordinators run real FE, EL and EX work in
the new platform for 4 weeks, with Softrend kept as a fallback.

## Tasks
- **P5.1** Go-live checklist and launch: production data for the branch,
  tablets ready, Softrend Service app kept installed as fallback.
- **P5.2** Weekly fix cycle: collect issues (in-app "report a problem" with
  logs), triage every Monday, release every Friday.
- **P5.3** Pilot measures: time per job vs Softrend (baseline from P0 timing),
  lost or re-entered inspections (target zero), sync failures, crash-free rate.
- **P5.4** Pilot review: written findings, what changes before rollout.

## Done when (P5 gate)
- [ ] 4 consecutive weeks with zero lost inspections
- [ ] Every performance budget met in Sentry field data
- [ ] Reports accepted by customers without rework
- [ ] The 3 technicians say inspections are faster than in Softrend
